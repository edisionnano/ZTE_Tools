# Root Passwords (Not Greek)
This repository was created to research vulnerabilities in ZTE routers provided by Greek ISPs. While doing so, I discovered default configurations from providers all arround the world with most of them including common root/superuser passwords. This file was created to gather these passwords that are of no Greek interest in hopes that they will help users of these ISPs.
